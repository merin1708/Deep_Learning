# Deep Learning Lab Experiments

A collection of Deep Learning lab implementations using TensorFlow, Keras, and PyTorch.

## Experiments Included

- **`enhancement.py`**: Image enhancement and brightness adjustment using Torchvision functional transforms.
- **`FFNN.py`**: Feedforward Neural Network (FFNN) on the CIFAR-10 dataset.
- **`image.py`**: Convolutional Neural Network (CNN) for handwritten digit recognition on the MNIST dataset.
- **`LR.py`**: Linear Regression using deep learning with Keras.
- **`lstm_gru.py`**: Comparison of SimpleRNN, LSTM, and GRU models for sentiment classification on the IMDB dataset.
- **`nifty50.py`**: Time series stock price prediction using LSTM on NIFTY 50 data.
- **`optim.py`**: Performance comparison of weight initialization (Xavier, Kaiming), Dropout, and L2 regularization on MNIST.
- **`review.py`**: Movie review sentiment analysis and interactive prediction using an LSTM model.
- **`vgg.py`**: Transfer learning using a pretrained VGG19 architecture on MNIST.
